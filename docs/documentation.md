# Документация проекта Geometric Lib

## Общее описание

**Geometric Lib** — учебная библиотека на языке Python для вычисления характеристик геометрических фигур.

Библиотека состоит из двух модулей:

- `circle.py` — функции для работы с кругом;
- `square.py` — функции для работы с квадратом.

Все функции снабжены подробными комментариями (docstring) с примерами вызова.

## Описание функций

### Модуль `circle.py`
#### area(r)

**Описание:** Вычисляет площадь круга.

**Параметры:**
- `r` (`int` | `float`) — Радиус круга.

**Возвращаемое значение:** `float` — Площадь круга.

**Пример вызова:**
```
>>> area(5)
78.53981633974483
```
---
#### perimeter(r)

**Описание:** Вычисляет периметр круга.

**Параметры:**
- `r` (`int` | `float`) — Радиус круга.

**Возвращаемое значение:** `float` — Перимитр круга.

**Пример вызова:**
```
>>> perimeter(5)
31.41592653589793
```
### Модуль `square.py`
#### area(r)

**Описание:** Вычисляет площадь квадрата.

**Параметры:**
- `r` (`int` | `float`) — Сторона квадрата.

**Возвращаемое значение:** `int` | `float` — Площадь квадрата.

**Пример вызова:**
```
>>> area(4)
16
```
---
#### perimeter(r)

**Описание:** Вычисляет периметр квадрата.

**Параметры:**
- `r` (`int` | `float`) — Сторона квадрата.

**Возвращаемое значение:** `int` | `float` — Перимитр квадрата.

**Пример вызова:**
```
>>> perimeter(4)

```
