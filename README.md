## 🧭 О проекте

**Geometric Lib** — учебная библиотека, созданная в рамках лабораторной работы по документированию.

## ✨ Возможности
- 📏 Вычисление площади.
- 📏 Вычисление периметра.

## 📋 Поддерживаемые фигуры
| Фигура | Модуль |
|:------:|:------:|
| 🟢 Круг | `circle.py` |
| 🟦 Квадрат |  `square.py` |

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/user193232/geometric_lib.git
cd geometric_lib
```

### 2. Установка

Дополнительные зависимости не требуются. Нужен только **Python 3.8+**.
